정상 하위유형과 대응 불량

현업에서 정상을 불량으로 잡던 케이스를 정상 클래스에 추가한 결과다. 새 정상 유형과 구분 대상이 되는 불량을 나란히 놓았고, 카드마다 사람이 보는 차트와 모델이 실제로 받는 224px 입력을 같이 실었다.
